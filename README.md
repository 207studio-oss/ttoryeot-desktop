# 또렷 데스크톱 내려받기

한글 문서(HWP·HWPX)를 열어 보는 무료 데스크톱 앱 **또렷**을 내려받는 곳입니다. 이 저장소에는 소스 코드가 없습니다.

[최신 릴리스](https://github.com/207studio-oss/ttoryeot-desktop/releases/latest)에서 받으세요.

- macOS (Apple Silicon·Intel): `ttoryeot-desktop-<판>-macos-universal.dmg`
- Windows (x64) 설치 파일: `ttoryeot-desktop-<판>-windows-x64-setup.exe`
- Windows (x64) 휴대용: `ttoryeot-desktop-<판>-windows-x64.zip`
- Linux: 데스크톱 앱은 없고 명령줄 도구만 있습니다. [207studio-oss/ttoryeot](https://github.com/207studio-oss/ttoryeot/releases/latest)

내려받은 파일은 같은 릴리스의 `SHA256SUMS`로 확인할 수 있습니다.
Windows 파일은 아직 코드 서명이 없어 SmartScreen 경고가 뜰 수 있습니다.
